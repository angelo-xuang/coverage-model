### Sheet 4: 假设

**场景切换控件**：
- A1 单元格：`活跃情景` 标签
- B1 单元格：数据验证下拉菜单（1=Bear, 2=Base, 3=Bull）

**三块假设并列**：

```
                    | Bear    | Base    | Bull    | 活跃值  |
                    |         |         |         | (=INDEX)|
```

**活跃值列公式**：
```

```
即 `=INDEX(C5:E5, $B$1)`，根据下拉值从对应情景列取值。

## 颜色编码

### 字体颜色

| 颜色 | RGB | 含义 |
|------|-----|------|
| 蓝色 | 0000FF | 硬编码输入值 |
| 黑色 | 000000 | 公式计算 |
| 绿色 | 008000 | 跨表链接（引用其他Sheet的值） |

### 单元格填充

| 区域 | 填充色 | 字体 |
|------|--------|------|
| 区域标题行 | #1F4E79（深蓝） | 白色粗体 |
| 列标题行 | #D9E1F2（浅蓝） | 黑色粗体 |
| 输入单元格 | #F2F2F2（浅灰）或白色 | 蓝色字体 |
| 公式单元格 | 白色 | 黑色字体 |
| 关键输出 | #BDD7EE（中蓝） | 黑色粗体 |
| 场景下拉 | #FFF2CC（浅黄） | 黑色粗体 |

## 数字格式

| 数据类型 | 格式 |
|----------|------|
| 金额 ($B) | `$#,##0.0` |
| 金额 ($M) | `$#,##0` |
| 百分比 | `0.0%` |

## 下拉菜单实现

使用 openpyxl 的 DataValidation：

```python
from openpyxl.worksheet.datavalidation import DataValidation

dv = DataValidation(type="list", formula1='"1,2,3"', allow_blank=False)
dv.error = "请选择1(Bear), 2(Base), 3(Bull)"
dv.errorTitle = "无效输入"
dv.prompt = "1=Bear, 2=Base, 3=Bull"
dv.promptTitle = "选择情景"
ws.add_data_validation(dv)
dv.add(ws["B1"])  # 下拉绑定到 B1 单元格

# B1 默认值
ws["B1"] = 2  # 默认Base
```

## INDEX 公式模式

假设假设表的 Bear/Base/Bull 分别在 C列/D列/E列，下拉在 B1：

```python
# 活跃值列（F列）的公式
ws["F5"] = '=INDEX(C5:E5,$B$1)'
# 拖拽到所有假设行
```

预测表中引用假设表的活跃值：

```python
# 绿色跨表链接
ws_forecast["B3"] = "=假设!F5"  # 绿色字体
```
