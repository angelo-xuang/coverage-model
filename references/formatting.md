## 数字格式

### 数据输入铁律

1. **能转换成数字就直接用数字**：`~48%` → `0.48`，`~5` → `5`，`~99` → `99`。不要在单元格里保留波浪号
2. **百分比统一保留两位小数**：格式 `0.00%`
3. **数字统一保留两位小数**：格式 `#,##0.00`（金额类）或 `#,##0`（整数类如GDP、年份）
4. **空值直接用空值**：Python `None`，不使用 `"-"`、`"--"`、空字符串等文本
5. **单元格内不要有货币单位**：写 `120` 而不是 `"$120B"`，用 `number_format` 控制显示
6. **单元格内不要有混合格式**：禁止 `"$705B    $125B（¥895B）"` 这种文本拼接
7. **估算值取中值**：`~48%` → `0.48`，`~5` → `5.00`

### 格式对照

| 数据类型 | 格式 | 示例 |
|----------|------|------|
| 金额 ($B) | `#,##0.00` | 470.00 |
| 金额 ($M) | `#,##0` | 24219 |
| 百分比 | `0.00%` | 0.48 显示为 48.00% |
| PE倍数 | `0.0"x"` | 25.0x |
| 增速 | `0.00%` | 0.5500 显示为 55.00% |
| 股价 ($) | `#,##0.00` | 225.32 |

## 下拉菜单实现

使用 openpyxl 的 DataValidation：

```python
from openpyxl.worksheet.datavalidation import DataValidation

dv = DataValidation(type="list", formula1='"1,2,3"', allow_blank=False)
dv.error = "请选择1(Bear), 2(Base), 3(Bull)"
dv.errorTitle = "无效输入"
dv.prompt = "1=Bear, 2=Base, 3=Bull"
dv.promptTitle = "选择情景"
ws.add_data_validation(dv)
dv.add(ws["B1"])  # 下拉绑定到 B1 单元格

# B1 默认值
ws["B1"] = 2  # 默认Base
```
