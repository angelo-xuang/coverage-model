# 方法论框架

## 1. 自上而下 TAM 预测方法

### 1.1 框架结构

```
行业总可触达市场 (TAM)
  × 可触达率 → 可服务市场 (SAM)
    × 市占率 → 公司收入
      × 毛利率 → 毛利
        - 运营费用 → EBIT
          × (1 - 税率) → 净利润
            × 目标PE → 隐含市值
```

### 1.2 TAM 预测方法

TAM 增长通常分三个阶段：

| 阶段 | 特征 | 增速特征 |
|------|------|----------|
| 起爆期 | 渗透率 <10%，技术验证刚过 | 高增速，50%+ CAGR |
| 主升浪 | 渗透率 10%-50%，需求爆发 | 中高速，20%-50% CAGR |
| 成熟期 | 渗透率 >50%，增量转存量 | 低速，<20% CAGR |

预测时需要判断目标公司所处阶段。每个情景对阶段划分可能不同：
- Bull: 认为仍在起爆期，高增长持续时间更长
- Base: 按当前主流判断
- Bear: 认为接近成熟，增速快速下降

### 1.3 市占率预测

市占率轨迹参考历史类比（见 §2）。

关键原则：
- 市占率不会无限上升，存在天花板（即使垄断也受反垄断制约）
- 技术周期中，先发优势通常在 3-5 年后衰减
- 供给瓶颈会限制市占率（即便有需求也供不上）

## 2. 可比公司/历史类比框架

### 2.1 选择类比对象的原则

类比对象需要满足：
1. **业务模式相似**：同为硬件/软件/平台/服务
2. **行业周期位置相似**：处于相似的技术采用阶段
3. **竞争格局相似**：市占率水平、竞争者数量
4. **时间距离可控**：优先选近10年的案例，太久远的参考价值下降

### 2.2 类比维度映射

| 预测维度 | 类比来源 | 数据点 |
|----------|----------|--------|
| 收入增速轨迹 | 同行业历史高增长公司 | CAGR、增速衰减曲线 |
| 市占率变化 | 历史上相似竞争格局的公司 | 峰值市占率、达到峰值的时间 |
| 毛利率走势 | 同模式公司（硬件/软件） | 峰值毛利率、毛利率压缩速度 |
| PE倍数 | 同行业可比公司 | 峰值PE、正常化PE |

### 2.3 常用类比案例库

以下为 AI 搜索时的优先候选（不是固定列表，根据行业动态调整）：

**半导体行业**：
- Intel Server CPU: 市占率从 90%+ 被蚕食到 70% 以下的轨迹
- Qualcomm Baseband: 从垄断到多供应商的利润率变化
- AMD vs Intel: 挑战者的增速轨迹

**网络设备**：
- Cisco Router: 从高速增长到成熟的完整周期
- 2000年 Cisco PE: 从 100x+ 到 15x 的估值压缩案例

**平台公司**：
- Apple iPhone: 硬件+生态的市占率和利润率稳定性
- AWS: 云基础设施的增速衰减曲线

### 2.4 类比使用规则

1. 不只看一个类比——至少找 2-3 个，取中间轨迹
2. 说明类比差异——为什么不完全适用
3. 类比用于定方向和量级，不是直接复制数字
4. 用户可以否决 AI 选的类比，指定自己的参照物

## 3. 定性→定量映射表

### 3.1 行业增长维度

| 判断 | TAM CAGR假设 | 增速衰减模式 |
|------|-------------|-------------|
| 高速增长 | 40%-60% | S曲线：前5年高增速，后5年逐步下降 |
| 稳健增长 | 15%-40% | 线性衰减：每年降 3-5 个百分点 |
| 成熟 | 5%-15% | 接近GDP增速 + 通胀 |
| 衰退 | -5%-5% | 行业萎缩，存量博弈 |

### 3.2 竞争壁垒维度

| 判断 | 市占率假设 | 市占率轨迹 |
|------|-----------|-----------|
| 极强护城河 | 维持或提升 5-10pp | 持平或缓慢上升 |
| 中等壁垒 | 维持当前水平 | 上下波动 ±3pp |
| 壁垒削弱 | 每年下降 2-5pp | 稳步下滑 |

### 3.3 利润率走势维度

| 判断 | 毛利率假设 | 费用率假设 |
|------|-----------|-----------|
| 扩张 | 每年提升 1-2pp | 规模效应下降 |
| 维持 | 维持近2年平均 | 维持近2年平均 |
| 收缩 | 每年下降 1-3pp | 因竞争需增加投入 |

### 3.4 估值水平维度

| 判断 | 目标PE倍数 | 参考基准 |
|------|-----------|---------|
| 高估 | 历史中位PE × 0.7-0.9 | 向均值回归 |
| 合理 | 历史中位PE × 0.9-1.1 | 维持当前水平 |
| 低估 | 历史中位PE × 1.1-1.3 | 折价修复 |

## 4. 三情景自动推导规则

用户确定 Base case 的4个维度后：

**Bull case**: 每个维度 +1 级
- 如果 Base 是"稳健增长"，Bull 变为"高速增长"
- 如果 Base 是"极强护城河"，已经是最高级，Bull 维持但参数取该级别上限

**Bear case**: 每个维度 -1 级
- 如果 Base 是"稳健增长"，Bear 变为"成熟"
- 如果 Base 是"成熟"，已经是较低级别，Bear 维持但参数取该级别下限

**边界处理**：
- 如果已经在最高/最低级，不再升级/降级，而是在该级别内调整参数到边界值
- Bull/Base/Bear 的假设差异应该**渐进式**，不是断崖式

## 5. 预测期细节

### 5.1 时间跨度

- 默认预测期：10年（当前年 + 10年）
- 如果是成熟行业：可以缩短到 7年
- 如果是颠覆性技术/超长周期：可以延长到 12年

### 5.2 增速衰减曲线

使用**S曲线衰减**而非线性衰减：

```python
# 第 t 年的增速 = 初始增速 × decay(t)
# decay(t) = 1 / (1 + exp(k * (t - midpoint)))
# k 控制衰减速度，midpoint 控制拐点位置
```

参数由定性判断决定：
- 高速增长：midpoint 靠后（第6-7年），k 较小（衰减缓慢）
- 稳健增长：midpoint 在中间（第4-5年）
- 成熟：midpoint 靠前（第2-3年），k 较大（快速衰减）

### 5.3 终值处理

模型不使用 DCF 终值。使用目标PE × 终年净利润作为终值。

原因：
- PE法更直观，个人投资者容易理解
- 避免永续增长率、WACC等假设的复杂性
- 不同情景用不同的目标PE已经体现了终值判断
