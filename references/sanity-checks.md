# 合理性检验框架

三层验证机制，建模完成后逐一执行。

---

## 第一层：内部逻辑验证（每个情景内部）

对 Bear、Base、Bull 三个情景**分别**执行以下检查。

### 1.1 增速合理性

| 检查项 | 规则 | 异常阈值 |
|--------|------|----------|
| 收入增速单调性 | 除特殊事件外，高增速应逐年递减 | 连续2年增速上升 |
| 绝对增速上限 | 不超过 TAM 增速 + 市占率提升带来的增量 | 单年增速 > TAM增速 × 1.5 |
| 绝对增速下限 | 成熟公司增速不应突然归零 | 单年增速 < -20%（除非行业衰退） |
| 收入规模上限 | 10年后的收入不应超过 TAM 本身 | 收入 > TAM × 80% |
| 增速衰减平滑性 | 相邻两年增速差不应太大 | |增速变化| > 30pp |

### 1.2 利润率合理性

| 检查项 | 规则 | 参考范围 |
|--------|------|----------|
| 毛利率范围 | 硬件公司通常 30%-70%，软件 60%-90% | 超出行业历史极值 |
| 毛利率变化速度 | 每年变化不超过 ±5pp | ±5pp |
| 费用率趋势 | 规模效应应使费用率缓慢下降或持平 | 费用率持续上升 >3年 |
| EBIT margin | 不应超过行业龙头历史峰值 | > 峰值 × 1.1 |
| 净利率 | 应低于毛利率，且为正（衰退情景除外） | 净利率 > 毛利率 |

### 1.3 估值合理性

| 检查项 | 规则 | 参考范围 |
|--------|------|----------|
| PE 倍数范围 | 不超过历史峰值，不低于 5x | 5x - 历史峰值 |
| 隐含市值增长 | 不应每年翻倍（即使高速增长期） | 年增长 > 100% |
| 隐含市值 vs 收入 | P/S 比应在合理范围 | P/S > 30x（除非 SaaS） |

---

## 第二层：跨情景排序验证

### 2.1 单调性检查

三个情景的每个指标必须满足排序：

```
Bull > Base > Bear
```

具体检查：

| 指标 | 必须满足 |
|------|----------|
| 终年收入 | Bull > Base > Bear |
| 终年净利 | Bull > Base > Bear |
| 终年隐含市值 | Bull > Base > Bear |
| CAGR | Bull > Base > Bear |
| 终年毛利率 | Bull ≥ Base ≥ Bear |
| 终年PE | Bull ≥ Base ≥ Bear |

### 2.2 差距合理性

相邻情景的差距不应太大或太小：

| 检查项 | 规则 |
|--------|------|
| Bull vs Base 差距 | 终年市值差异在 30%-100% |
| Base vs Bear 差距 | 终年市值差异在 30%-100% |
| 差距对称性 | Bull-Base 和 Base-Bear 的差距不应差超过 3倍 |
| CAGR差异 | 相邻情景 CAGR 差 2-8pp |

如果差距过大（>200%），说明某个情景的假设极端，需标记警告。

如果差距过小（<10%），说明三个情景没有实质区别，失去了情景分析的意义。

---

## 第三层：外部基准对比

### 3.1 可比公司对比

将预测结果与可比公司历史数据对比：

| 对比项 | 方法 | 异常判定 |
|--------|------|----------|
| 收入 CAGR | vs 类比公司在相似阶段的 CAGR | 超出类比 ±50% |
| 峰值市占率 | vs 类比公司的历史峰值 | 超过类比峰值 +10pp |
| 峰值毛利率 | vs 同行业历史最高 | 超过行业最高 +5pp |
| 峰值 PE | vs 类比公司在类似增长阶段的 PE | 超过类比峰值 × 1.3 |

### 3.2 行业增速对比

| 对比项 | 数据源 | 异常判定 |
|--------|--------|----------|
| TAM 增速 vs 行业共识 | WebSearch 行业报告 | 偏离共识 > 20pp |
| 公司增速 vs 行业增速 | 公司增速不应长期大幅超越行业 | 持续 > 行业 × 2 |

### 3.3 市场共识对比（如有）

| 对比项 | 异常判定 |
|--------|----------|
| Base case 终年收入 vs 分析师一致预期 | 偏差 > 30% |
| Base case PE vs 当前市场 PE | 偏差 > 50% |

## 验证结果输出格式

```
=== 合理性检验报告 ===

第一层：内部逻辑
  [Base] 收入增速: ✓ 通过
  [Base] 利润率: ✓ 通过
  [Base] 估值: ⚠ 第8年PE=85x，接近历史峰值(88x)，注意
  [Bull] 收入增速: ✗ 第6年增速上升，不符合衰减假设 → 建议调整
  [Bear] 全部通过

第二层：跨情景排序
  单调性: ✓ 全部 Bull > Base > Bear
  差距合理性: ⚠ Bull vs Base 差距仅12%，差异过小

第三层：外部基准
  vs Intel 历史轨迹: ✓ CAGR在合理范围
  vs 行业共识: ⚠ Base case TAM增速45%，共识约35%，偏离+10pp
```

标记说明：
- ✓ 通过
- ⚠ 警告（可以接受，但需注意）
- ✗ 不通过（必须讨论是否调整）
